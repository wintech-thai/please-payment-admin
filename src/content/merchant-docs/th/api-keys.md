# API Keys

API Key คือ "กุญแจดิจิทัล" ที่ให้ระบบหลังบ้านของร้านคุณเอง (ไม่ใช่คน) ใช้ยืนยันตัวตนเวลาเรียก API เช่น เวลาเว็บไซต์ของคุณต้องสร้างคำขอรับเงินอัตโนมัติทุกครั้งที่ลูกค้ากดสั่งซื้อ ระบบของคุณจะใช้ API Key นี้แนบไปกับทุกคำขอ เพื่อบอกว่า "นี่คือระบบของร้านนี้จริง ๆ"

## ภาพหน้าจอ

![หน้ารายการ API Keys](/docs/merchant/api-keys/api-keys-01.png)

| หมายเลข | คืออะไร |
|---|---|
| 1 | ปุ่ม "Add Key" และปุ่มลบแบบเลือกหลายรายการ |
| 2 | คอลัมน์: ชื่อ Key, คำอธิบาย, Custom Role, Roles, สถานะ |
| 3 | เมนู Action: ปิดใช้งาน Key / เปิดใช้งาน Key |

## สิ่งที่คุณทำได้ในหน้านี้

### สร้าง API Key ใหม่

![หน้าสร้าง API Key](/docs/merchant/api-keys/api-keys-02.png)

| หมายเลข | คืออะไร |
|---|---|
| 1 | Key Information — ชื่อ Key (จำเป็น) และคำอธิบาย |
| 2 | Roles & Permissions — เลือก Custom Role |
| 3 | System Roles — ตัวเลือกสิทธิ์แบบสองฝั่ง (เลือกจากซ้ายแล้วกดลูกศรย้ายไปฝั่ง "Selected Roles" ทางขวา) |

1. กดปุ่ม **"Add Key"**
2. กรอก **ชื่อ Key** (จำเป็น) และคำอธิบาย (ไม่บังคับ)
3. กำหนดสิทธิ์ที่ Key นี้จะใช้ได้ — เลือกจาก **Custom Role** ที่เคยสร้างไว้ (ดู[กำหนดสิทธิ์การใช้งาน](/documents/merchant/custom-roles)) และ/หรือเลือก **Roles** ของระบบจากรายการฝั่งซ้าย แล้วกดปุ่มลูกศรย้ายไปฝั่ง "เลือกแล้ว" ทางขวา
4. กด **บันทึก**

![Modal แสดงค่า Secret Key](/docs/merchant/api-keys/api-keys-03.png)

| หมายเลข | คืออะไร |
|---|---|
| 1 | ค่า Secret Key (แสดงเพียงครั้งเดียว) พร้อมปุ่มคัดลอก |
| 2 | ปุ่ม "Done & Return" |

<div class="warning-box">
  <p class="warning-title">สำคัญมาก — อ่านก่อนปิดหน้าต่าง</p>
  <ul>
    <li>หลังสร้างสำเร็จ ระบบจะแสดง<strong>ค่า Secret Key เพียงครั้งเดียวเท่านั้น</strong> ในกล่องข้อความพร้อมปุ่มคัดลอก</li>
    <li><strong>คัดลอกและเก็บค่านี้ไว้ในที่ปลอดภัยทันที</strong> เช่น ระบบจัดการรหัสผ่าน (password manager) หรือไฟล์ตั้งค่าที่เข้าถึงได้เฉพาะทีมพัฒนา</li>
    <li>ถ้าปิดหน้าต่างไปโดยไม่ได้คัดลอก จะ<strong>ไม่สามารถดูค่า Secret Key เดิมได้อีก</strong> — ต้องสร้าง Key ใหม่แทนเท่านั้น</li>
  </ul>
</div>

### แก้ไข Key ที่มีอยู่

คลิกชื่อ Key ในรายการเพื่อแก้ไขชื่อ คำอธิบาย หรือเปลี่ยน Custom Role/Roles ที่ผูกไว้ — การแก้ไขจะ**ไม่แสดงหรือเปลี่ยนค่า Secret Key เดิม** เปลี่ยนได้เฉพาะข้อมูลและสิทธิ์เท่านั้น

### เปิด/ปิดการใช้งาน Key

ใช้เมนู Action ในแต่ละแถวเพื่อ**ปิดใช้งานชั่วคราว**โดยไม่ต้องลบ (เหมาะเวลาสงสัยว่า Key รั่วไหลแต่ยังไม่แน่ใจ อยากหยุดใช้งานไว้ก่อน) หรือ**เปิดใช้งานกลับมา**เมื่อพร้อมใช้อีกครั้ง

### ลบ API Key

เลือก Key ที่ต้องการแล้วกดลบ ระบบจะเตือนชัดเจนว่า **"บริการที่ใช้ Key นี้จะหมดสิทธิ์เข้าถึงทันที"** — ตรวจสอบให้แน่ใจก่อนว่าไม่มีระบบใดกำลังใช้ Key นี้อยู่จริงก่อนลบ

<div class="tip-box">
  <p class="tip-title">เกร็ดน่ารู้</p>
  <ul>
    <li>ถ้าลืมคัดลอก Secret Key ไม่ต้องพยายามหาทางกู้คืน — สร้าง Key ใหม่แล้วนำไปตั้งค่าในระบบของคุณแทนได้เลย จากนั้นค่อยลบ Key เก่าทิ้ง</li>
    <li>แนะนำให้สร้าง Key แยกตามระบบ/บริการที่ใช้งาน แทนที่จะใช้ Key เดียวกันทุกที่ เพื่อให้ปิดการใช้งานเฉพาะจุดได้ง่ายหากมีปัญหา</li>
  </ul>
</div>
