# ประวัติการใช้งาน (Audit Log)

หน้านี้คือ "กล้องวงจรปิด" ของระบบ — บันทึกทุกการเรียกใช้งาน API ที่เกิดขึ้นกับบัญชีร้านค้าคุณไว้ทั้งหมด ไม่ว่าจะเป็นการกระทำจากคนที่ล็อกอินเข้ามา หรือจาก API Key ที่ระบบของคุณใช้เรียกอัตโนมัติ ใช้เมื่อต้องตรวจสอบความปลอดภัย หรือไล่หาสาเหตุว่าทำไมบางอย่างถึงไม่เป็นไปตามที่คาดไว้

## ภาพหน้าจอ

![หน้า Audit Log](/docs/merchant/audit-log/audit-log-01.png)

| หมายเลข | คืออะไร |
|---|---|
| 1 | ตัวกรอง: ค้นหา (ทุกช่อง/ชื่อผู้ใช้/API/IP Address) และช่วงเวลา (ค่าเริ่มต้น 30 วันล่าสุด) |
| 2 | กราฟฮิสโตแกรม — ปริมาณการเรียกใช้งานตามช่วงเวลา แยกสีตาม API ที่เรียกบ่อยที่สุด พร้อมจำนวน hits รวม |
| 3 | คอลัมน์ตาราง: เวลา, ชื่อผู้ใช้, ประเภทตัวตน (ID Type), API ที่เรียก, สถานะ (HTTP status), บทบาท, IP Address |
| 4 | ปุ่มดูรายละเอียด (ไอคอนรูปตา) เปิด panel ข้อมูลแบบเต็ม |

## สิ่งที่คุณทำได้ในหน้านี้

### ค้นหาและกรองบันทึก

เลือกช่วงเวลาที่สนใจ แล้วค้นหาแบบเจาะจงได้ 3 แบบ: ค้นหาทุกช่อง, เฉพาะชื่อผู้ใช้, หรือเฉพาะ IP Address — มีประโยชน์มากเวลาต้องการตรวจสอบว่า "คนนี้ทำอะไรไปบ้างช่วงนี้" หรือ "IP นี้เรียก API อะไรบ้าง"

### อ่านกราฟฮิสโตแกรม

กราฟด้านบนแสดงปริมาณการเรียกใช้งานเป็นช่วง ๆ ตามเวลา ช่วยให้เห็นจุดที่มีการเรียกใช้งานผิดปกติ (สูงหรือต่ำผิดจากปกติ) ได้เร็ว โดยไม่ต้องไล่อ่านทีละแถวในตาราง

### สังเกตรายการที่มีปัญหา

**แถวไหนที่มีสถานะ HTTP ไม่ใช่ 200 (สำเร็จ) จะถูกไฮไลต์เป็นสีแดงทั้งแถว** ตั้งแต่ชื่อผู้ใช้ไปจนถึงชื่อ API ที่เรียก ทำให้มองเห็นรายการที่ผิดพลาดได้ทันทีโดยไม่ต้องอ่านคอลัมน์สถานะทีละบรรทัด

### ดูรายละเอียดเต็มของแต่ละรายการ

คลิกไอคอนรูปตาเพื่อเปิด panel รายละเอียด ดูได้ทั้งแบบตารางฟิลด์และแบบ JSON ดิบ พร้อมช่องค้นหาภายใน panel เอง และปุ่มเลื่อนดูรายการก่อนหน้า/ถัดไปโดยไม่ต้องปิด panel
