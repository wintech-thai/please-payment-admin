# กำหนดสิทธิ์การใช้งาน (Custom Roles)

Custom Role คือ "ชุดสิทธิ์" ที่คุณตั้งชื่อเองได้ เช่น "พนักงานบัญชี" หรือ "ทีมพัฒนา" โดยกำหนดเองว่าใครที่ได้รับบทบาทนี้จะเรียกใช้ฟังก์ชัน (API) ไหนของระบบได้บ้าง จากนั้นนำบทบาทนี้ไปผูกกับ[ผู้ใช้งาน](/documents/merchant/users)หรือ[API Key](/documents/merchant/api-keys)ได้ทันที แทนที่จะต้องมานั่งกำหนดสิทธิ์ทีละคน

## ภาพหน้าจอ

![หน้ารายการ Custom Roles](/docs/merchant/custom-roles/custom-roles-01.png)

| หมายเลข | คืออะไร |
|---|---|
| 1 | ปุ่ม "Add Role" และปุ่มลบแบบเลือกหลายรายการ |
| 2 | คอลัมน์: ชื่อบทบาท, คำอธิบาย, แท็ก |
| 3 | ช่องค้นหา |

## สิ่งที่คุณทำได้ในหน้านี้

### สร้างบทบาทใหม่

กดปุ่ม "Add Role" แล้วกรอก:

![หน้าสร้างบทบาทใหม่](/docs/merchant/custom-roles/custom-roles-02.png)

| หมายเลข | คืออะไร |
|---|---|
| 1 | Role Information — ชื่อบทบาท (จำเป็น), คำอธิบาย, แท็ก |
| 2 | ช่องค้นหาสิทธิ์ (Search permissions) |
| 3 | ตัวนับ "เลือกแล้ว / ทั้งหมด" |
| 4 | รายการกลุ่มสิทธิ์ (แยกตามกลุ่มฟังก์ชันของระบบ) พร้อม checkbox เลือกทั้งกลุ่มหรือเลือกทีละรายการ |

1. **ชื่อบทบาท** (จำเป็น) — ตั้งชื่อให้สื่อความหมาย เช่น "ทีมบัญชี-ดูอย่างเดียว"
2. **คำอธิบาย** และ **แท็ก** (ไม่บังคับ) — ช่วยจัดหมวดหมู่และค้นหาในภายหลัง
3. **เลือกสิทธิ์** — ใช้ช่องค้นหาเพื่อกรองหาฟังก์ชันที่ต้องการ แล้วติ๊กเลือกทีละรายการ หรือติ๊กที่หัวข้อกลุ่มเพื่อเลือกทั้งกลุ่มในครั้งเดียว

<div class="warning-box">
  <p class="warning-title">เข้าใจให้ถูกก่อนตั้งบทบาท</p>
  <ul>
    <li>บทบาทที่นี่คือ<strong>รายการฟังก์ชัน (API) แบบละเอียด</strong> ไม่ใช่แค่ระดับสิทธิ์กว้าง ๆ อย่าง "แอดมิน"/"พนักงาน" — คุณต้องเลือกเองว่าอนุญาตฟังก์ชันไหนบ้าง ถ้าไม่ติ๊กฟังก์ชันไหนไว้ คนที่ได้รับบทบาทนี้จะ<strong>ไม่สามารถ</strong>ใช้ฟังก์ชันนั้นได้เลย</li>
    <li>ควรเลือกเฉพาะสิทธิ์ที่จำเป็นจริง ๆ ต่อหน้าที่งาน (หลักการ "ให้สิทธิ์เท่าที่จำเป็น") เพื่อลดความเสี่ยงด้านความปลอดภัย</li>
  </ul>
</div>

### แก้ไขบทบาทเดิม

คลิกชื่อบทบาทในรายการเพื่อเข้าไปแก้ไข ฟอร์มจะโหลดสิทธิ์ที่เคยเลือกไว้มาติ๊กให้อัตโนมัติ แก้ไขแล้วกดบันทึกได้ทันที (ถ้าออกจากหน้าโดยไม่ได้บันทึกการเปลี่ยนแปลง ระบบจะถามยืนยันก่อนเสมอ)

### ลบบทบาท

เลือกบทบาทที่ต้องการ (เลือกได้หลายรายการพร้อมกัน) แล้วกดลบ — ระบบจะให้ยืนยันอีกครั้งก่อนลบจริงเสมอ เพราะการลบไม่สามารถย้อนกลับได้

<div class="tip-box">
  <p class="tip-title">เกร็ดน่ารู้</p>
  <ul>
    <li>ถ้ามีผู้ใช้งานหรือ API Key ที่ผูกกับบทบาทนี้อยู่ ควรตรวจสอบก่อนลบว่าจะไม่กระทบสิทธิ์การใช้งานของพวกเขา</li>
  </ul>
</div>
