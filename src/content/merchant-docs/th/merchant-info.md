# ข้อมูลร้านค้า (Merchant Info)

หน้านี้คือ "ป้ายทะเบียน" ของร้านค้าคุณในระบบ Please Payment — รวมทุกอย่างที่บอกว่าร้านคุณถูกตั้งค่าไว้อย่างไร ตั้งแต่ค่าธรรมเนียม วงเงินสูงสุดต่อวัน ไปจนถึง URL ที่ทีมพัฒนาของคุณต้องใช้เชื่อมต่อ API

<div class="warning-box">
  <p class="warning-title">ข้อควรรู้ก่อนเริ่ม</p>
  <ul>
    <li>ทุกช่องในหน้านี้เป็น <strong>ข้อมูลสำหรับดูเท่านั้น (read-only)</strong> ไม่มีปุ่มแก้ไข/บันทึกใด ๆ ในหน้านี้เลย</li>
    <li>หากต้องการเปลี่ยนค่าธรรมเนียม วงเงิน หรือการตั้งค่าใด ๆ ที่เห็นในหน้านี้ ให้ติดต่อทีมงาน Please Payment หรือผู้ดูแลระบบของคุณ</li>
  </ul>
</div>

หน้านี้มีทั้งหมด 4 แท็บ แต่ละแท็บหน้าตาต่างกันมาก จึงมีภาพหน้าจอแยกให้ทีละแท็บด้านล่างนี้

## สิ่งที่คุณทำได้ในหน้านี้

### แท็บ "ข้อมูล" (Info)

![แท็บ Info](/docs/merchant/merchant-info/merchant-info-01.png)

| หมายเลข | คืออะไร |
|---|---|
| 1 | ป้ายสถานะร้านค้า (Active / Disabled / Pending) |
| 2 | แถบแท็บ: ข้อมูล (Info), Payment Endpoint, Webhooks, Wallet Summary |
| 3 | ข้อมูลพื้นฐาน: รหัสร้านค้า ชื่อ อีเมล เบอร์โทร สถานะ |
| 4 | การ์ดค่าธรรมเนียม: % ค่าธรรมเนียมฝั่งรับเงิน (Pay-In) และฝั่งจ่ายเงิน (Pay-Out) |
| 5 | การ์ดวงเงิน: จำนวนเงินต่อรายการ และวงเงินรวมต่อวัน (เลื่อนหน้าลงเพื่อดู Payout Partial Count Limit และการตั้งค่าการตัดเศษสตางค์/ระยะเวลาหมดอายุคำขอรับเงินที่อยู่ถัดจากส่วนนี้) |

แท็บแรกที่เปิดมาเจอ รวมข้อมูลตั้งค่าหลักของร้านคุณ:

- **ข้อมูลพื้นฐาน** — รหัสร้านค้า ชื่อร้าน อีเมล เบอร์โทร และสถานะบัญชี
- **ค่าธรรมเนียม (Fees)** — เปอร์เซ็นต์ที่ระบบหักทุกครั้งที่มีเงินเข้า (Pay-In Fee) และทุกครั้งที่มีเงินออก (Pay-Out Fee) ใช้ตัวเลขนี้ประกอบการคำนวณต้นทุนต่อธุรกรรมของคุณ
- **วงเงิน (Limits)** — จำนวนเงินต่ำสุด/สูงสุดที่อนุญาตต่อ 1 รายการ ทั้งฝั่งรับเงินและจ่ายเงิน รวมถึง**วงเงินรวมต่อวัน**ทั้งจำนวนเงินและจำนวนรายการ พร้อมแถบสีบอกว่าตอนนี้ใช้ไปกี่เปอร์เซ็นต์ของวงเงิน (เขียว = ยังเหลือเยอะ, เหลือง = ใกล้เต็ม 70-90%, แดง = ใกล้เต็มวงเงินมาก ≥90%) หากเห็นแถบสีแดงบ่อย ๆ ควรติดต่อทีมงานเพื่อขอปรับวงเงินให้เหมาะกับปริมาณธุรกรรมจริง
- **Payout Partial Count Limit (P2P)** — จำนวนครั้งสูงสุดที่คำขอถอนเงิน 1 รายการ จะถูกจับคู่กับเงินที่ลูกค้าโอนเข้ามาหลาย ๆ ครั้ง (ดูรายละเอียดเพิ่มเติมที่หน้า [คำขอถอนเงิน](/documents/merchant/pay-out-requests))
- **การตัดเศษสตางค์ (Discard Cent)** — ถ้าเปิดใช้งาน ระบบจะปัดเศษสตางค์ออกจากยอดที่เรียกเก็บอัตโนมัติ
- **ระยะเวลาหมดอายุของคำขอรับเงิน** — คำขอรับเงิน (Pay-In Request) แต่ละใบจะหมดอายุกี่นาทีหลังสร้าง หากลูกค้าไม่โอนเงินภายในเวลานี้ คำขอจะถือเป็นโมฆะ

### แท็บ "Payment Endpoint"

![แท็บ Payment Endpoint](/docs/merchant/merchant-info/merchant-info-02.png)

| หมายเลข | คืออะไร |
|---|---|
| 1 | ตาราง Payment Request Endpoints (ประเภท, URL, ปุ่มคัดลอก) |
| 2 | ลิงก์ "View API Documentation" |
| 3 | ส่วน IP Whitelist / Blacklist (เลื่อนหน้าลงเพื่อดูรายการ Web/API Whitelist และ Blacklist ทั้งหมด) |

แท็บนี้สำหรับทีมพัฒนา (developer) ของร้านคุณโดยเฉพาะ — รวม URL ของ API ที่ต้องใช้ยิงคำขอสร้างรายการรับ/จ่ายเงินจากระบบหลังบ้านของคุณเอง

- ตาราง **Payment Request Endpoints** แสดงประเภทและ URL แต่ละ endpoint พร้อมปุ่มคัดลอก (คลิกแล้วจะขึ้นสถานะ "คัดลอกแล้ว" ชั่วครู่)
- ลิงก์ **"View API Documentation"** พาไปยังเอกสาร Public API Docs ฉบับเต็มสำหรับนักพัฒนา
- รายการ **IP Whitelist / Blacklist** — ระบุ IP ที่ได้รับอนุญาต (Whitelist) หรือถูกบล็อก (Blacklist) ทั้งฝั่งหน้าเว็บ (Web) และฝั่ง API แยกกัน ใช้ตรวจสอบว่าระบบของคุณเชื่อมต่อจาก IP ที่ถูกต้องหรือไม่

<div class="tip-box">
  <p class="tip-title">เกร็ดน่ารู้</p>
  <ul>
    <li>คำขอรับเงิน (Pay-In Request) <strong>ไม่ได้สร้างจากหน้าเว็บนี้</strong> — ต้องสร้างผ่านการเรียก API จาก endpoint ที่แสดงในแท็บนี้เท่านั้น ดูวิธีเรียกใช้แบบละเอียดได้จาก "View API Documentation"</li>
  </ul>
</div>

### แท็บ "Webhooks"

![แท็บ Webhooks](/docs/merchant/merchant-info/merchant-info-03.png)

| หมายเลข | คืออะไร |
|---|---|
| 1 | ชื่อ Event (ป้ายสี) |
| 2 | คำอธิบาย Event |
| 3 | Endpoint URL + HTTP method |
| 4 | สถานะ Active/Inactive |

Webhook คือกลไกที่ระบบใช้ "แจ้งข่าว" กลับไปยังระบบของคุณโดยอัตโนมัติ เช่น เมื่อมีการจ่ายเงินสำเร็จ ระบบจะยิงข้อมูลไปที่ URL ที่ตั้งค่าไว้ทันที แท็บนี้แสดงรายการ Webhook ที่ตั้งค่าไว้ (ชื่อ Event, คำอธิบาย, URL ปลายทาง + HTTP method, สถานะการใช้งาน)

<div class="warning-box">
  <p class="warning-title">ข้อควรรู้</p>
  <ul>
    <li>หน้านี้ใช้ <strong>ดูรายการ Webhook เท่านั้น</strong> ไม่มีปุ่มสร้าง/แก้ไข Webhook ในระบบ Merchant หากต้องการเพิ่มหรือแก้ไข Webhook ให้ติดต่อทีมงาน Please Payment</li>
  </ul>
</div>

### แท็บ "Wallet Summary"

![แท็บ Wallet Summary](/docs/merchant/merchant-info/merchant-info-04.png)

| หมายเลข | คืออะไร |
|---|---|
| 1 | ยอดคงเหลือกระเป๋าเงิน (Current Balance) |
| 2 | แถบวงเงินรับเงินรายวัน (Pay-In Daily Amount) |
| 3 | ตาราง Wallet Transactions |
| 4 | ป้าย Tag ที่คลิกได้ในแต่ละแถว (ลิงก์ไปยังรายการต้นทาง) |

แสดงยอดคงเหลือและประวัติการเคลื่อนไหวของกระเป๋าเงิน (Wallet) ของร้านค้าคุณ — ถ้าร้านค้าคุณยังไม่ได้เปิดใช้งานกระเป๋าเงิน แท็บนี้จะแสดงข้อความแจ้งว่ายังไม่มีการตั้งค่า

- ยอดคงเหลือปัจจุบัน (Wallet Balance) ตัวเลขใหญ่ด้านบน พร้อมแถบวงเงินรับเงินต่อวัน (ถ้ามีการตั้งค่าไว้)
- ตาราง **Wallet Transactions** — ประวัติทุกรายการที่กระทบยอดกระเป๋าเงิน เรียงตามวันที่ แต่ละแถวบอกว่าเป็นเงินเข้า (Pay-In, สีเขียว) เงินออก (Pay-Out, สีแดง) หรือการถอนเงิน (Withdraw) พร้อมยอดคงเหลือก่อนหน้าและยอดคงเหลือหลังรายการนั้น — ใช้ตรวจสอบย้อนหลังได้ว่ายอดเงินเปลี่ยนแปลงจากรายการไหนบ้าง
- คลิกที่ป้ายชื่อรายการ (Tag) ในตารางเพื่อเปิดดูรายละเอียดรายการต้นทางนั้น ๆ (เช่น คำขอรับเงิน หรือคำขอถอนเงินที่เกี่ยวข้อง) ในแท็บใหม่

<div class="tip-box">
  <p class="tip-title">เกร็ดน่ารู้</p>
  <ul>
    <li>บางรายการเป็นธุรกรรม P2P ข้าม merchant ซึ่งระบบจะไม่อนุญาตให้คุณเปิดดูรายละเอียด (จะขึ้นข้อความแจ้งเตือนแทนการเปิดหน้าใหม่) ถือเป็นพฤติกรรมปกติของระบบ ไม่ใช่ข้อผิดพลาด</li>
  </ul>
</div>
