# สร้างคำขอรับเงิน (Pay-In Requests)

Pay-In Request คือ "คำขอให้ลูกค้าโอนเงินมาให้คุณ" หนึ่งใบต่อหนึ่งการขอรับเงินหนึ่งครั้ง — ปกติจะมาพร้อม QR Code หรือเลขที่บัญชีปลายทางให้ลูกค้าโอนเข้ามา หน้านี้คือที่ที่คุณติดตามได้ว่าคำขอแต่ละใบเป็นอย่างไรบ้าง มีคนโอนเงินมาหรือยัง และจับคู่สำเร็จหรือไม่

<div class="warning-box">
  <p class="warning-title">คำขอรับเงินไม่ได้สร้างจากหน้านี้</p>
  <ul>
    <li>หน้านี้ใช้ <strong>ดูและติดตาม</strong> คำขอรับเงินเท่านั้น ไม่มีปุ่ม "สร้างใหม่"</li>
    <li>คำขอรับเงินทุกใบถูกสร้างโดย <strong>ระบบหลังบ้านของร้านคุณเอง</strong> ผ่านการเรียก API (ดู URL ได้ที่แท็บ Payment Endpoint ในหน้า <a href="/documents/merchant/merchant-info">ข้อมูลร้านค้า</a>) เช่น เมื่อลูกค้ากดชำระเงินบนเว็บ/แอปของคุณ ระบบของคุณจะยิง API มาที่นี่เพื่อขอ QR Code ให้ลูกค้าสแกน</li>
  </ul>
</div>

## ภาพหน้าจอ

![หน้ารายการ Pay-In Requests](/docs/merchant/pay-in-requests/pay-in-requests-01.png)

| หมายเลข | คืออะไร |
|---|---|
| 1 | ตัวกรอง: ค้นหาข้อความ, สถานะ, ประเภท P2P, ช่วงเวลา |
| 2 | ปุ่มรีเฟรช และปุ่ม Export CSV |
| 3 | คอลัมน์ตาราง: วันที่ (คลิกเพื่อดูรายละเอียด), ร้านค้า, จำนวนเงิน, ค่าธรรมเนียม, บัญชีปลายทาง, ผู้จ่ายเงิน, สถานะ, เลขอ้างอิง |
| 4 | ป้ายแจ้งเตือน (ไอคอนสามเหลี่ยม) — คลิกเพื่อดูบันทึกคำเตือนอัตโนมัติของระบบที่ผูกกับรายการนี้ (ถ้ามีลูกค้าแนบสลิปมาด้วย จะมีป้ายไอคอนคลิปหนีบกระดาษแสดงจำนวนสลิปอยู่ข้าง ๆ กัน) |

## สิ่งที่คุณทำได้ในหน้านี้

### ค้นหาและกรองรายการ

ใช้ช่องค้นหาแบบ full-text ร่วมกับตัวกรองสถานะและช่วงเวลา เพื่อหาคำขอรับเงินที่ต้องการได้เร็วขึ้น เช่น กรองเฉพาะสถานะ "รอดำเนินการ" เพื่อดูว่ามีคำขอไหนที่ลูกค้ายังไม่โอนเงินมาบ้าง

### อ่านสถานะแต่ละรายการ

| สถานะ | ความหมาย |
|---|---|
| **สำเร็จ (Paid / Approved)** | ระบบจับคู่คำขอนี้กับเงินที่โอนเข้ามาได้แล้ว จะมีลิงก์ไปยังรายการรับเงินจริง (Pay-In Transaction) ที่เกิดขึ้น |
| **รอดำเนินการ (Pending)** | ยังไม่มีเงินโอนเข้ามาตรงกับคำขอนี้ จะมีตัวเลขอายุของคำขอ (เช่น "12 นาที", "2 ชม. 5 นาที") ให้ดูว่ารอมานานแค่ไหนแล้ว |
| **ผิดพลาด (Rejected / Error)** | ไม่สามารถยืนยัน/จับคู่รายการได้ มักมีเหตุผลกำกับให้ดูใต้สถานะ |

### เปิดดูรายละเอียดคำขอ

![หน้ารายละเอียด Pay-In Request](/docs/merchant/pay-in-requests/pay-in-requests-02.png)

| หมายเลข | คืออะไร |
|---|---|
| 1 | ข้อมูลทั่วไป (General Information) — วันที่สร้าง/หมดอายุ, จำนวนเงิน, บัญชีธนาคารปลายทาง, เลขอ้างอิง |
| 2 | ปุ่ม Slip Link — สร้างลิงก์/QR ให้ลูกค้าอัปโหลดสลิป |
| 3 | สถานะ + ป้ายแจ้งเตือน (ถ้ามี) |

คลิกที่วันที่ในแต่ละแถวเพื่อเข้าไปดูรายละเอียดเต็ม ๆ ของคำขอนั้น ในหน้ารายละเอียดคุณจะเห็น:

- **ข้อมูลทั่วไป** — วันที่สร้าง วันหมดอายุ จำนวนเงินที่ขอ/ที่สร้างจริง บัญชีธนาคารปลายทาง เลขอ้างอิง 1-3
- **สลิปที่แนบมา** — ถ้ามีลูกค้าอัปโหลดสลิปมาผูกกับคำขอนี้ กดปุ่ม "สลิป (จำนวน)" เพื่อเปิดดูภาพสลิปแบบเต็มจอ เลื่อนดูได้ทีละใบถ้ามีหลายใบ
- **Slip Link** — ปุ่มสร้างลิงก์/QR Code แบบใช้ครั้งเดียว ไว้ส่งให้ลูกค้าเปิดเพื่ออัปโหลดสลิปโอนเงินสำหรับคำขอนี้โดยเฉพาะ เผื่อกรณีระบบจับคู่อัตโนมัติไม่สำเร็จและต้องยืนยันด้วยสลิปแทน
- **ขั้นตอนการประมวลผล** — ลำดับการทำงานที่ระบบดำเนินการกับคำขอนี้ (ถ้ามี)

<div class="tip-box">
  <p class="tip-title">เกร็ดน่ารู้</p>
  <ul>
    <li>ถ้าเห็นแบนเนอร์สีแดงเตือนว่า "พบเลขอ้างอิงสลิปซ้ำ" พร้อมลิงก์ไปยังคำขออื่น หมายความว่าสลิปที่แนบมามีเลขอ้างอิงเดียวกับสลิปที่เคยอัปโหลดไว้กับคำขออื่นแล้ว — ระบบเตือนไว้เพื่อป้องกันการใช้สลิปซ้ำ ควรตรวจสอบก่อนดำเนินการต่อ</li>
    <li>ป้ายแจ้งเตือน (Notices) ที่เห็นในหลาย ๆ หน้าของระบบ (ไม่ใช่แค่หน้านี้) ใช้กลไกเดียวกันหมด — คลิกดูรายละเอียดได้เสมอว่าเกิดจากอะไร</li>
  </ul>
</div>
