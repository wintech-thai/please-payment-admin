# ประวัติรายการรับเงิน (Pay-In Transactions)

ถ้า Pay-In Request คือ "การขอให้ลูกค้าโอนเงินมา" Pay-In Transaction ก็คือ**หลักฐานที่ยืนยันแล้วว่าเงินก้อนนั้นเข้ามาจริง** — ทุกครั้งที่มีเงินโอนเข้าบัญชีธนาคารของร้านคุณและระบบตรวจพบ จะถูกบันทึกเป็นรายการในหน้านี้ ไม่ว่าจะจับคู่กับคำขอรับเงินได้หรือไม่ก็ตาม

## ภาพหน้าจอ

![หน้ารายการ Pay-In Transactions](/docs/merchant/pay-in-transactions/pay-in-transactions-01.png)

| หมายเลข | คืออะไร |
|---|---|
| 1 | ตัวกรอง: ค้นหา, สถานะ, P2P, ช่วงเวลา |
| 2 | ปุ่มรีเฟรช และปุ่ม Export CSV |
| 3 | คอลัมน์ตาราง: วันที่, ร้านค้า, จำนวนเงิน, ค่าธรรมเนียม, บัญชีปลายทาง, ผู้จ่ายเงิน, สถานะ (พร้อมลิงก์ไปยังคำขอรับเงินต้นทางเมื่อจับคู่สำเร็จ), เลขอ้างอิง |

## สิ่งที่คุณทำได้ในหน้านี้

### อ่านสถานะแต่ละรายการ

| สถานะ | ความหมาย |
|---|---|
| **จับคู่ได้ (Identified / Approved)** | เงินที่เข้ามาถูกจับคู่กับคำขอรับเงินใบใดใบหนึ่งเรียบร้อยแล้ว มีลิงก์ให้ดูคำขอต้นทาง |
| **จับคู่ไม่ได้ (UnIdentified)** | เงินเข้ามาจริง แต่ยังหาคำขอรับเงินที่ตรงกันไม่เจอ — จะมีตัวเลขบอกว่ารอมานานเท่าไหร่แล้ว |
| **ผิดพลาด (Error / Rejected)** | เกิดข้อผิดพลาดระหว่างประมวลผลรายการนี้ |

### ดูรายละเอียดรายการ

![หน้ารายละเอียด Pay-In Transaction](/docs/merchant/pay-in-transactions/pay-in-transactions-02.png)

| หมายเลข | คืออะไร |
|---|---|
| 1 | ข้อมูลทั่วไป (General Information) — วันที่, สถานะ, จำนวนเงิน, บัญชีที่รับเงิน, เลขอ้างอิง |
| 2 | Payment Request ID — ลิงก์กลับไปยังคำขอรับเงินต้นทาง |
| 3 | ข้อมูลค่าธรรมเนียม (Fee Information) — Tx Amount, Fee Rate, Pay-In Fee, และ Net Amount (ยอดสุทธิ) |

คลิกวันที่เพื่อเปิดรายละเอียด จะเห็น:

- **ข้อมูลทั่วไป** — จำนวนเงิน สกุลเงิน บัญชีธนาคารที่รับเงิน เลขอ้างอิง และลิงก์กลับไปยังคำขอรับเงินต้นทาง (ถ้ามี)
- **ข้อมูลค่าธรรมเนียม** — จำนวนเงินที่รับจริง (ก่อนหักค่าธรรมเนียม), % ค่าธรรมเนียม, จำนวนค่าธรรมเนียมที่ถูกหัก และ **ยอดสุทธิที่ร้านคุณได้รับจริง** (ยอดหลังหักค่าธรรมเนียมแล้ว) — ตัวเลขนี้คือยอดที่ควรใช้กระทบยอดบัญชีจริง ไม่ใช่ยอดเต็มก่อนหักค่าธรรมเนียม
- **ข้อมูลผู้โอน** — ชื่อบัญชี/ธนาคารของคนที่โอนเงินมา (ถ้าระบบตรวจพบข้อมูลนี้)
- **ขั้นตอนการประมวลผล** — ลำดับที่ระบบใช้ตรวจสอบและจับคู่รายการนี้
