# คำขอถอนเงิน (Pay-Out Requests)

หน้านี้ตรงข้ามกับ Pay-In Request — แทนที่จะขอรับเงินเข้า คำขอถอนเงิน (Pay-Out Request) คือการขอให้ระบบ**จ่ายเงินออก**ไปยังบัญชีธนาคารปลายทาง เช่น คืนเงินให้ลูกค้า จ่ายเงินให้คู่ค้า หรือถอนกำไรออกจากระบบ

<div class="warning-box">
  <p class="warning-title">คำขอถอนเงินไม่ได้สร้างจากหน้านี้</p>
  <ul>
    <li>หน้านี้ใช้ <strong>ดูและติดตาม</strong> คำขอถอนเงินเท่านั้น</li>
    <li>การสร้างคำขอถอนเงินใหม่เป็นขั้นตอนที่ดำเนินการทาง<strong>ฝั่ง Admin</strong> ไม่ใช่จากหน้า Merchant นี้ — หากต้องการถอนเงิน ให้ติดต่อทีมงาน/ผู้ดูแลระบบของคุณเพื่อสร้างคำขอให้</li>
  </ul>
</div>

## ภาพหน้าจอ

![หน้ารายการ Pay-Out Requests](/docs/merchant/pay-out-requests/pay-out-requests-01.png)

| หมายเลข | คืออะไร |
|---|---|
| 1 | ตัวกรอง: ค้นหา, สถานะ, ประเภท, ช่วงเวลา |
| 2 | คอลัมน์ตาราง: วันที่, ร้านค้า, จำนวนเงิน, ค่าธรรมเนียม + ผู้รับผิดชอบค่าธรรมเนียม, บัญชีปลายทาง (To), บัญชีต้นทาง (From), สถานะ, เลขอ้างอิง |
| 3 | ป้าย "Withdraw" (แสดงเมื่อรายการนี้เป็นการถอนเงินออกจากระบบ) |
| 4 | ป้ายแจ้งเตือน (Notices) |

## สิ่งที่คุณทำได้ในหน้านี้

### ติดตามสถานะคำขอ

| สถานะ | ความหมาย |
|---|---|
| **สำเร็จ (Paid / Approved)** | เงินถูกโอนออกไปยังปลายทางเรียบร้อยแล้ว |
| **รอดำเนินการ (Pending)** | คำขออยู่ระหว่างรอดำเนินการ จะมีตัวเลขอายุคำขอแสดงให้ดู |
| **ผิดพลาด (Rejected / Failed)** | ไม่สามารถดำเนินการได้ พร้อมเหตุผล |
| **ยกเลิก (Cancelled)** | คำขอถูกยกเลิก |

### อ่านรายละเอียดคำขอ

![หน้ารายละเอียด Pay-Out Request](/docs/merchant/pay-out-requests/pay-out-requests-02.png)

| หมายเลข | คืออะไร |
|---|---|
| 1 | จำนวนเงินที่ขอถอน (Amount) |
| 2 | ค่าธรรมเนียมและผู้รับผิดชอบค่าธรรมเนียม (Fee Payer) |
| 3 | QR Code สำหรับใช้อ้างอิงตอนโอนเงิน (หรือข้อมูลบัญชีตรง ๆ ถ้าไม่รองรับ QR) |
| 4 | สถานะ + ป้ายแจ้งเตือน |

รายการที่เป็น P2P จะมีตาราง "Partial Payouts" เพิ่มขึ้นมาต่อจากส่วนนี้ (ดูหัวข้อถัดไป)

คลิกวันที่จากหน้ารายการเพื่อเปิดดูรายละเอียด จะเห็นบัญชีปลายทาง จำนวนเงิน ค่าธรรมเนียมและยอดสุทธิ พร้อม **ผู้รับผิดชอบค่าธรรมเนียม (Fee Payer)** — ระบุว่าค่าธรรมเนียมการถอนเงินครั้งนี้หักจาก "ร้านค้า" ของคุณ หรือหักจาก "ผู้รับเงินปลายทาง" (ถ้าเป็นแบบหลัง ยอดที่ปลายทางได้รับจะน้อยกว่ายอดที่ขอถอนเต็มจำนวน)

### ทำความเข้าใจกลไก P2P / Partial Payout

คำขอถอนเงินบางรายการไม่ได้จ่ายออกจากยอดคงเหลือของร้านคุณโดยตรง แต่ระบบจะ**จับคู่กับเงินที่ลูกค้ารายอื่นกำลังโอนเข้ามาพอดี** แล้วส่งเงินนั้นต่อไปยังปลายทางที่ระบุไว้ทันที (เรียกว่า P2P) — คำขอเดียวสามารถถูกจับคู่แบบนี้ได้หลายครั้งจนกว่าจะครบยอดเต็ม (Partial Payout) โดยมีจำนวนครั้งสูงสุดกำหนดไว้ต่อร้านค้า (ดูค่านี้ได้ที่หน้า [ข้อมูลร้านค้า](/documents/merchant/merchant-info))

ในหน้ารายละเอียดของคำขอที่เป็น P2P จะมีตาราง **"Partial Payouts"** แสดงให้เห็นว่าตอนนี้จ่ายไปแล้วเท่าไหร่ ผ่านการจับคู่กี่ครั้ง และยังเหลืออีกเท่าไหร่กว่าจะครบยอด

### ใช้ QR Code สำหรับการโอนเงิน

หน้ารายละเอียดของคำขอจะแสดง QR Code ไว้ให้อ้างอิงเวลาโอนเงินไปยังปลายทาง — ถ้าบัญชี/ธนาคารปลายทางไม่รองรับการสร้าง QR ระบบจะแสดงข้อมูลบัญชีตรง ๆ ให้ใช้โอนด้วยมือแทน

  <p class="tip-title">เกร็ดน่ารู้</p>

    <li>การอนุมัติคำขอถอนเงินเป็นขั้นตอนที่ทีมงาน Please Payment ดำเนินการฝั่งหลังบ้าน ไม่มีปุ่มอนุมัติในหน้านี้</li>
