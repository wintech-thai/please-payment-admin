# ประวัติรายการถอนเงิน (Pay-Out Transactions)

หน้านี้คือบันทึกที่ยืนยันแล้วของเงินที่**ถูกโอนออกจากระบบไปจริง** หลังจากคำขอถอนเงิน ([Pay-Out Request](/documents/merchant/pay-out-requests)) ได้รับการดำเนินการเรียบร้อยแล้ว

## ภาพหน้าจอ

![หน้ารายการ Pay-Out Transactions](/docs/merchant/pay-out-transactions/pay-out-transactions-01.png)

| หมายเลข | คืออะไร |
|---|---|
| 1 | ตัวกรอง: ค้นหา, สถานะ, ประเภท, ช่วงเวลา |
| 2 | ปุ่มรีเฟรช และปุ่ม Export CSV |
| 3 | คอลัมน์ตาราง: วันที่ (+ป้าย Withdraw ถ้ามี), จำนวนเงิน, ค่าธรรมเนียม + ผู้รับผิดชอบค่าธรรมเนียม, บัญชีปลายทาง, บัญชีต้นทาง, สถานะ, เลขอ้างอิง |

## สิ่งที่คุณทำได้ในหน้านี้

### อ่านสถานะแต่ละรายการ

| สถานะ | ความหมาย |
|---|---|
| **สำเร็จ (Completed / Success / Paid)** | เงินถูกโอนออกไปยังปลายทางเรียบร้อยแล้ว |
| **ผิดพลาด (Failed / Error / Rejected)** | ดำเนินการไม่สำเร็จ พร้อมเหตุผล |
| **กำลังดำเนินการ (Pending / Processing)** | ยังอยู่ระหว่างขั้นตอนโอนเงิน จะมีตัวเลขอายุแสดงให้ดู |

### ดูรายละเอียดรายการ

![หน้ารายละเอียด Pay-Out Transaction](/docs/merchant/pay-out-transactions/pay-out-transactions-02.png)

| หมายเลข | คืออะไร |
|---|---|
| 1 | ข้อมูลทั่วไป (General Information) — วันที่, สถานะ, จำนวนเงิน, เลขอ้างอิง |
| 2 | Pay-Out Request ID — ลิงก์กลับไปยังคำขอถอนเงินต้นทาง |
| 3 | ข้อมูลค่าธรรมเนียม (Fee Information) — Tx Amount, Fee Rate, Pay-Out Fee, และ Net Amount |
| 4 | ข้อมูลปลายทาง (Destination Information) — ธนาคารและเลขบัญชีที่รับเงิน |

คลิกวันที่เพื่อเปิดรายละเอียด จะเห็น:

- **ข้อมูลทั่วไป** — จำนวนเงิน สกุลเงิน ลิงก์กลับไปยังคำขอถอนเงินต้นทาง เลขอ้างอิง
- **ข้อมูลค่าธรรมเนียม** — % ค่าธรรมเนียม จำนวนค่าธรรมเนียม และ **ยอดสุทธิที่ปลายทางได้รับจริง** หลังหักค่าธรรมเนียม (ยอดนี้จะต่างจากยอดเต็มถ้าค่าธรรมเนียมถูกกำหนดให้ผู้รับปลายทางเป็นผู้จ่าย)
- **บัญชีปลายทาง (Destination)** — บัญชีที่รับเงินจริง
- **บัญชีต้นทาง (Source)** — บัญชีที่ใช้จ่ายเงินออกจริง (แสดงเฉพาะเมื่อระบบทราบข้อมูลนี้)
