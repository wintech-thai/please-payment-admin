# แจ้งปัญหา/ขอความช่วยเหลือ (Support Case)

เมื่อเจอปัญหาการใช้งาน หรือมีคำถามที่ต้องการให้ทีมงาน Please Payment ช่วยเหลือ หน้านี้คือช่องทางหลักในการแจ้งเรื่องและติดตามความคืบหน้า — เหมือนเปิดตั๋ว (ticket) แล้วคุยกับทีมซัพพอร์ตผ่านหน้าเว็บโดยตรง

## ภาพหน้าจอ

![หน้ารายการ Support Case](/docs/merchant/support-case/support-case-01.png)

| หมายเลข | คืออะไร |
|---|---|
| 1 | ตัวกรอง: สถานะ, ค้นหา, ช่วงเวลา |
| 2 | ปุ่ม "Create Case" |
| 3 | คอลัมน์ตาราง: เลขอ้างอิง, หัวข้อ, สถานะ, ระดับความสำคัญ, ผู้แจ้ง, วันที่สร้าง/อัปเดต |

## สิ่งที่คุณทำได้ในหน้านี้

### สร้าง Case ใหม่

กดปุ่ม **"Create Case"** แล้วกรอก:

![หน้าสร้าง Support Case](/docs/merchant/support-case/support-case-02.png)

| หมายเลข | คืออะไร |
|---|---|
| 1 | Subject — หัวข้อ (จำเป็น, ไม่เกิน 200 ตัวอักษร) |
| 2 | Priority — การ์ดเลือกระดับความสำคัญ 4 ระดับ |
| 3 | Description — กล่องข้อความอธิบายปัญหาแบบ rich text (แนบรูปได้) |

1. **หัวข้อ** (จำเป็น, ไม่เกิน 200 ตัวอักษร) — ตั้งให้สั้นแต่สื่อปัญหาชัดเจน
2. **ระดับความสำคัญ** (จำเป็น) เลือกจาก 4 ระดับ:
   - **Low** — คำถามทั่วไป/ข้อเสนอแนะ
   - **Medium** (ค่าเริ่มต้น) — ปัญหาทั่วไป
   - **High** — ปัญหาที่กระทบต่อธุรกรรม
   - **Critical** — ระบบใช้งานไม่ได้/ล่ม
3. **รายละเอียด** (จำเป็น) — อธิบายปัญหาให้ละเอียดที่สุดเท่าที่ทำได้ในกล่องข้อความ (แนบรูปภาพประกอบได้) ยิ่งให้ข้อมูลครบ ทีมงานยิ่งช่วยได้เร็วขึ้น เช่น เกิดขึ้นตอนไหน ทำอะไรอยู่ก่อนเจอปัญหา มีข้อความ error อะไรขึ้นบ้าง

กด **ส่ง** เพื่อสร้าง Case — ระบบจะพากลับไปหน้ารายการพร้อม Case ใหม่ที่สร้างขึ้น

### ติดตามสถานะ Case

| สถานะ | ความหมาย |
|---|---|
| **New** | เพิ่งสร้าง ยังไม่มีคนรับเรื่อง |
| **Open** | ทีมงานรับเรื่องแล้ว |
| **In Progress** | กำลังดำเนินการแก้ไข |
| **Waiting for Customer** | ทีมงานรอข้อมูลเพิ่มเติมจากคุณ |
| **Resolved** | แก้ไขเสร็จสิ้นแล้ว |
| **Closed** | ปิด Case |
| **Cancelled** | ยกเลิก Case |

### สนทนากับทีมซัพพอร์ต

![หน้ารายละเอียดและสนทนา Support Case](/docs/merchant/support-case/support-case-03.png)

| หมายเลข | คืออะไร |
|---|---|
| 1 | ข้อมูล Case — เลขอ้างอิง, องค์กร, ความสำคัญ, ผู้สร้าง, วันที่สร้าง/อัปเดตล่าสุด |
| 2 | รายละเอียดปัญหา (คำอธิบายที่กรอกตอนสร้าง Case) |
| 3 | การสนทนา — ข้อความของคุณ (Merchant) อยู่ฝั่งขวา สีเขียว, ข้อความจากทีมงาน (Admin) อยู่ฝั่งซ้าย |
| 4 | ช่องพิมพ์ข้อความตอบกลับ |

เปิด Case ที่ต้องการเพื่อดูรายละเอียดและพูดคุยกับทีมงานแบบแชท — ข้อความของคุณจะอยู่ฝั่งขวา ข้อความจากทีมงานจะอยู่ฝั่งซ้าย พิมพ์ข้อความในช่องด้านล่างแล้วกดส่งได้เลย หากต้องการตอบกลับข้อความใดข้อความหนึ่งโดยเฉพาะ วางเมาส์บนข้อความนั้นแล้วกด "Reply" เพื่ออ้างอิงข้อความนั้นในคำตอบของคุณ

<div class="warning-box">
  <p class="warning-title">ข้อควรรู้</p>
  <ul>
    <li>เมื่อ Case ถูกปิดในสถานะ <strong>Resolved</strong> หรือ <strong>Closed</strong> แล้ว จะ<strong>ไม่สามารถส่งข้อความเพิ่มในเคสนั้นได้อีก</strong> — หากมีปัญหาเกี่ยวเนื่อง ให้สร้าง Case ใหม่แทน</li>
  </ul>
</div>
