# จัดการผู้ใช้งาน (Users)

หน้านี้ใช้จัดการว่า**ใครในทีมของคุณเข้าใช้งานระบบ Please Payment ได้บ้าง** และแต่ละคนทำอะไรในระบบได้บ้าง — ตั้งแต่เชิญสมาชิกใหม่ กำหนดสิทธิ์ ไปจนถึงช่วยรีเซ็ตรหัสผ่านให้เมื่อจำเป็น

## ภาพหน้าจอ

![หน้ารายการผู้ใช้งาน](/docs/merchant/users/users-01.png)

| หมายเลข | คืออะไร |
|---|---|
| 1 | ปุ่ม "Add User" และปุ่มลบแบบเลือกหลายรายการ |
| 2 | คอลัมน์: ชื่อผู้ใช้ (พร้อมป้าย "Owner" ถ้าเป็นเจ้าของบัญชี), แท็ก, Custom Role, Roles, ผู้ใช้งานคนแรกของระบบ (Initial User), สถานะ |
| 3 | เมนู Action: ปิดใช้งาน / เปิดใช้งาน / สร้างลิงก์รีเซ็ตรหัสผ่าน / สร้างลิงก์ลงทะเบียนใหม่ |

## สิ่งที่คุณทำได้ในหน้านี้

### เชิญผู้ใช้งานใหม่เข้าทีม

กดปุ่ม **"Add User"** แล้วกรอก:

![หน้าเชิญผู้ใช้ใหม่](/docs/merchant/users/users-02.png)

| หมายเลข | คืออะไร |
|---|---|
| 1 | User Information — ชื่อผู้ใช้และอีเมล (จำเป็นทั้งคู่), แท็ก |
| 2 | Roles & Permissions — Custom Role และ System Roles |

1. **ชื่อผู้ใช้** และ **อีเมล** (จำเป็นทั้งคู่)
2. แท็ก (ไม่บังคับ) — ใช้จัดหมวดหมู่ เช่น ตามแผนก
3. กำหนดสิทธิ์ให้คนนี้ — เลือก **Custom Role** และ/หรือ **Roles** ของระบบ (แบบเดียวกับตอนสร้าง [API Key](/documents/merchant/api-keys))
4. กด **Add User**

หลังส่งสำเร็จ ระบบจะแสดง**ลิงก์ลงทะเบียน (Registration Link)** แบบใช้ครั้งเดียวให้คุณคัดลอกไปส่งต่อให้คนที่ถูกเชิญ (เช่น ทางแชทหรืออีเมล) เพื่อให้เขาเปิดลิงก์และตั้งรหัสผ่านของตัวเอง — ถ้าไม่เห็นลิงก์ในหน้าต่างสำเร็จ หมายความว่าบัญชีถูกสร้างในสถานะ "รอดำเนินการ (Pending)" ไว้ก่อน ให้ไปสร้างลิงก์ใหม่จากเมนู Action ในรายการแทน

### แก้ไขสิทธิ์ผู้ใช้ที่มีอยู่

คลิกชื่อผู้ใช้ในรายการเพื่อแก้ไข — แก้ได้เฉพาะ **แท็ก, Custom Role, และ Roles** เท่านั้น

<div class="warning-box">
  <p class="warning-title">ข้อควรรู้</p>
  <ul>
    <li><strong>ชื่อผู้ใช้และอีเมลแก้ไขไม่ได้</strong>หลังจากสร้างบัญชีแล้ว หากพิมพ์ผิดตอนเชิญ ต้องลบบัญชีเดิมแล้วเชิญใหม่แทน</li>
  </ul>
</div>

### จัดการสถานะบัญชีผู้ใช้

ใช้เมนู Action ในแต่ละแถว:

- **ปิดใช้งาน / เปิดใช้งาน** — ระงับหรือคืนสิทธิ์การล็อกอินชั่วคราว โดยไม่ต้องลบบัญชี
- **สร้างลิงก์รีเซ็ตรหัสผ่าน** — สร้างลิงก์ให้ผู้ใช้ตั้งรหัสผ่านใหม่ ใช้เมื่อผู้ใช้ลืมรหัสผ่านและต้องการให้ผู้ดูแลช่วย
- **สร้างลิงก์ลงทะเบียน** — ใช้ได้เฉพาะบัญชีที่ยังอยู่สถานะ "รอดำเนินการ" สำหรับสร้างลิงก์เชิญใหม่ กรณีลิงก์เดิมหมดอายุหรือหาไม่เจอแล้ว

<div class="warning-box">
  <p class="warning-title">ข้อควรระวังเรื่องลิงก์</p>
  <ul>
    <li>ลิงก์รีเซ็ตรหัสผ่านและลิงก์ลงทะเบียนเป็นแบบ<strong>ใช้ครั้งเดียวและหมดอายุหลังใช้งาน</strong> — อย่าเผยแพร่ในที่สาธารณะ ให้ส่งตรงถึงเจ้าของบัญชีเท่านั้น</li>
  </ul>
</div>

### ลบผู้ใช้งาน

เลือกผู้ใช้ที่ต้องการ (เลือกได้หลายคนพร้อมกัน) แล้วกดลบ — ยืนยันอีกครั้งก่อนลบจริงเสมอ
