# 操作日志 (Audit Log)

这个页面就像系统的"监控摄像头"——完整记录了商户账号发生的每一次 API 调用，无论是登录用户的操作，还是您的系统自动通过 API Key 发起的调用。当您需要进行安全检查，或排查某些结果为何不符合预期时，都可以使用此页面。

## 页面截图

![Audit Log 页面](/docs/merchant/audit-log/audit-log-01.png)

| 编号 | 说明 |
|---|---|
| 1 | 筛选条件：搜索（全部字段 / 用户名 / API / IP 地址）与时间范围（默认为最近 30 天） |
| 2 | 直方图 — 按时间段显示调用量，按最常调用的 API 分色显示，并附总命中次数 |
| 3 | 表格列：时间、用户名、身份类型 (ID Type)、调用的 API、状态 (HTTP status)、角色、IP 地址 |
| 4 | 详情按钮（眼睛图标）— 打开完整信息面板 |

## 您可以在此页面做什么

### 搜索与筛选记录

选择您关注的时间范围，然后可用 3 种方式精确搜索：全字段搜索、仅按用户名搜索、或仅按 IP 地址搜索——在需要确认"这个人最近做了什么"或"这个 IP 都调用过哪些 API"时非常有用。

### 读懂直方图

上方的图表按时间段显示调用量，帮助您快速发现异常的调用情况（明显偏高或偏低），无需逐行翻查表格。

### 留意有问题的记录

**HTTP 状态不为 200（成功）的行会被整行标红**，从用户名到调用的 API 名称都会高亮显示，让您无需逐行查看状态列，也能立即发现出错的记录。

### 查看单条记录的完整详情

点击眼睛图标打开详情面板，可切换查看字段表格或原始 JSON 两种形式，面板内还提供搜索框，以及无需关闭面板即可切换查看上一条/下一条记录的按钮。
