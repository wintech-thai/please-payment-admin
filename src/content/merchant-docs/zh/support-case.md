# 问题反馈/寻求帮助 (Support Case)

当您在使用过程中遇到问题，或有需要 Please Payment 团队协助的疑问时，此页面就是提交问题和追踪处理进度的主要渠道——就像开一张工单 (ticket)，直接在网页上与支持团队沟通。

## 页面截图

![Support Case 列表页面](/docs/merchant/support-case/support-case-01.png)

| 编号 | 说明 |
|---|---|
| 1 | 筛选条件：状态、搜索、时间范围 |
| 2 | "Create Case" 按钮 |
| 3 | 表格列：编号、标题、状态、优先级、提交人、创建/更新日期 |

## 您可以在此页面做什么

### 创建新 Case

点击 **"Create Case"** 按钮，然后填写：

![创建 Support Case 页面](/docs/merchant/support-case/support-case-02.png)

| 编号 | 说明 |
|---|---|
| 1 | Subject — 标题（必填，不超过 200 个字符） |
| 2 | Priority — 以卡片形式选择 4 个优先级之一 |
| 3 | Description — 用于描述问题的富文本输入框（可附加图片） |

1. **标题**（必填，不超过 200 个字符）——简短但要能清楚说明问题
2. **优先级**（必填），从以下 4 个等级中选择：
   - **Low** — 一般性问题/建议
   - **Medium**（默认）— 常见问题
   - **High** — 影响交易的问题
   - **Critical** — 系统无法使用/宕机
3. **详细说明**（必填）——在文本框中尽可能详细地描述问题（可附加图片辅助说明）。提供的信息越完整，团队就能越快提供帮助，例如：问题发生的时间、发生前您正在进行的操作、出现了哪些错误提示等。

点击**提交**以创建 Case——系统会带您返回列表页面，并显示刚创建的新 Case。

### 追踪 Case 状态

| 状态 | 含义 |
|---|---|
| **New** | 刚创建，尚未有人接手 |
| **Open** | 团队已接手此 Case |
| **In Progress** | 正在处理中 |
| **Waiting for Customer** | 团队正在等待您提供更多信息 |
| **Resolved** | 已处理完成 |
| **Closed** | Case 已关闭 |
| **Cancelled** | Case 已取消 |

### 与支持团队沟通

![Support Case 详情与对话页面](/docs/merchant/support-case/support-case-03.png)

| 编号 | 说明 |
|---|---|
| 1 | Case 信息 — 编号、所属组织、优先级、创建人、创建/最近更新日期 |
| 2 | 问题详情（创建 Case 时填写的描述内容） |
| 3 | 对话记录 — 您（Merchant）发送的消息显示在右侧，绿色；团队（Admin）发送的消息显示在左侧 |
| 4 | 回复消息输入框 |

打开您要查看的 Case，即可看到详情，并以聊天的形式与团队沟通——您的消息显示在右侧，团队的消息显示在左侧。在下方输入框中输入内容后点击发送即可。如果想针对某一条具体消息进行回复，将鼠标悬停在该消息上，点击 "Reply" 即可在您的回复中引用该消息。

<div class="warning-box">
  <p class="warning-title">请注意</p>
  <ul>
    <li>当 Case 被关闭为 <strong>Resolved</strong> 或 <strong>Closed</strong> 状态后，<strong>将无法再在该 Case 中发送消息</strong>——如果有相关的后续问题，请另外创建新的 Case。</li>
  </ul>
</div>
