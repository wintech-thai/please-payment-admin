# LINE Agent

This video walks through the **LINE Agent** settings page on the Admin side, used to connect and configure automated notifications sent via LINE to the relevant people.

By the end, you'll be able to set up LINE notifications for your team — useful when your team wants to know about important events in real time via LINE instead of constantly checking the system.

## What this video covers

- **Registering a new LINE API Agent** — Agent Code, a description (to identify the merchant/purpose of this agent), LINE Username, LINE API Key, Agent Image Tag, and linking the bank accounts this agent relates to
- **Viewing the list of Agents** in the "Agent Management" table — enabling/disabling with a toggle and checking connection status (e.g. connected successfully, ready)
- **Viewing Event Messages** for an Agent — a log table of events/messages the Agent sends and receives via LINE, with search and Channel/Event filters
