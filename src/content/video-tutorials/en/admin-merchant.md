# Merchant

This video walks through the **Merchant** page on the Admin side — the list of every merchant in the organization, including adding a new merchant, editing existing merchant details, and configuring per-merchant settings.

By the end, you'll be able to manage merchants end-to-end, from onboarding a new one to managing its API access — useful for admins setting up a new merchant or maintaining existing ones.

## What this video covers

- **Viewing the list of every merchant in the organization**, with search/filtering
- **Creating a new merchant** — Organization ID, merchant name, contact email and phone, fee rates (account setup fee / other fees %), enabling/disabling the shared Global Bank Account, Payment Request expiry time, min/max amount per transaction, daily transaction amount limit, and daily transaction count limit
- **Editing an existing merchant's details** using the same form
- **Managing a merchant's API Keys & Users**:
  - Viewing all 4 API endpoints (Pay-In, Pay-In (P2P), Pay-Out, Withdrawal) with a copy button
  - Configuring Whitelist/Blacklist IPs to restrict where requests can come from
  - Creating and managing API keys (name, permissions, creation date, status)
  - Inviting a new user to the merchant — generates a registration link for the user to set their own password, after which they appear in the user list with a role (e.g. Owner) and status
