# Admin Overview

This video walks through the **Overview** page on the Admin side — the first page an administrator sees after logging in. It's used to see transaction totals across **every merchant in the organization** in one place, without opening each merchant individually.

## What this video covers

- How to pick a time range (1 day, 7 days, 30 days, or a custom range) and how to refresh the data
- What each summary card means — Pay-In, Pay-Out, Withdraw, Fees, and merchant counts by status (Active/Inactive)
- How to read the daily transaction bar chart and the merchant-share pie chart
- How to switch between data types — Pay-In, Pay-Out, Fees, and Withdraw — using the sub-tabs on the same page
