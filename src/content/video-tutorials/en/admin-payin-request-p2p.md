# Pay-In Request (P2P)

This video walks through the **Pay-In Request (P2P)** page on the Admin side — Pay-In requests specifically for transfers between merchants, separate from regular Pay-In requests that collect money from outside customers.

By the end, you'll be able to create a transfer request between merchants in the system — useful when two merchants need to move or settle funds with each other without going through an outside channel.

## What this video covers

- **Creating a new QR Payment (P2P) request** through its own dedicated dialog, separate from the regular QR Payment one — amount, payer name, REF 1/REF 2 — generating a QR code plus a slip upload link in the same dialog
- **Viewing P2P Pay-In requests** in the same Pay-In Requests table as regular ones, with status (Pending/Approved/Rejected), and approving/rejecting via the Confirm Approve dialog
- **Tracking the result after approval** — once a P2P request is approved, it automatically shows up as a Pay-Out on the sending merchant's side too (since it's moving funds between merchants within the system, not collecting from an outside customer)
