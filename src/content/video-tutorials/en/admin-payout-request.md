# Pay-Out Request

This video walks through the **Pay-Out Request** page on the Admin side, used to view and manage Pay-Out requests across every merchant in the organization in one place.

By the end, you'll be able to create and approve withdrawal/transfer requests on a merchant's behalf — useful for admins or support staff who need to process a withdrawal or review a transfer request for a merchant.

## What this video covers

- **Adding a Pay-Out bank account** used to send money out — bank (e.g. BAY), PromptPay type, account number, the phone number it's registered to, and which merchant(s) use it
- **Creating a new Pay-Out request** — source merchant, destination as either another Merchant in the system or an external Beneficiary, amount, and REF 1/REF 2/REF 3
- **Viewing the list of Pay-Out requests** with columns for merchant, amount, source/destination account, and status (Pending/Approving/Approved)
- **Approving a request**, plus an example of the "Merchant wallet has insufficient balance" warning, which shows the current balance against the requested amount
- **Viewing a bank account's wallet balance**, reflecting both Pay-In (credit) and Pay-Out (debit) entries in the same transaction history table
