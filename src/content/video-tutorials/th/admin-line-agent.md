# LINE Agent

วิดีโอนี้พาไปดูหน้าตั้งค่า **LINE Agent** ในฝั่ง Admin ซึ่งใช้สำหรับเชื่อมต่อและตั้งค่าการแจ้งเตือนอัตโนมัติผ่าน LINE ไปยังผู้ที่เกี่ยวข้อง

ดูจบแล้วคุณจะตั้งค่าการแจ้งเตือนผ่าน LINE ให้ทีมงานได้เอง — เหมาะกับทีมที่ต้องการรับรู้เหตุการณ์สำคัญแบบเรียลไทม์ผ่าน LINE แทนการเข้าเช็กระบบตลอดเวลา

## วิดีโอนี้พูดถึงอะไรบ้าง

- **ลงทะเบียน LINE API Agent ใหม่** — กรอก Agent Code, คำอธิบาย (ใช้สำหรับระบุชื่อร้าน/จุดประสงค์ของ Agent), LINE Username, LINE API Key, Agent Image Tag และผูกบัญชีธนาคารที่เกี่ยวข้องกับ Agent นี้
- **ดูรายการ Agent ทั้งหมด** ในตาราง "การจัดการ Agent" — เปิด/ปิดการใช้งานด้วย toggle และเช็คสถานะการเชื่อมต่อ (เช่น เชื่อมต่อสำเร็จ, ready)
- **ดู Event Messages** ของแต่ละ Agent — ตาราง log เหตุการณ์/ข้อความที่ Agent รับส่งผ่าน LINE พร้อมช่องค้นหาและตัวกรองตาม Channel/Event
