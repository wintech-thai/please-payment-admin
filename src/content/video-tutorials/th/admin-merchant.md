# ร้านค้า

วิดีโอนี้พาไปดูหน้า **ร้านค้า (Merchant)** ฝั่ง Admin สำหรับดูรายชื่อร้านค้า (Merchant) ทั้งหมดที่อยู่ในองค์กร รวมถึงการเพิ่มร้านค้าใหม่ แก้ไขข้อมูลร้านค้าที่มีอยู่ และตั้งค่าต่าง ๆ ของแต่ละร้าน

ดูจบแล้วคุณจะจัดการร้านค้าในระบบได้ครบวงจร ตั้งแต่เพิ่มร้านค้าใหม่ไปจนถึงดูแล API ของร้านค้า — เหมาะกับแอดมินที่ต้องตั้งค่าร้านค้าใหม่หรือดูแลร้านค้าที่มีอยู่

## วิดีโอนี้พูดถึงอะไรบ้าง

- **ดูรายชื่อร้านค้าทั้งหมดในองค์กร** พร้อมค้นหา/กรองรายการ
- **สร้างร้านค้าใหม่** — กรอก Organization ID, ชื่อร้าน, อีเมล, เบอร์โทรติดต่อ, ตั้งค่าค่าธรรมเนียม (% ค่าธรรมเนียมเปิดบัญชี/ค่าธรรมเนียมอื่น ๆ), เปิด/ปิดการใช้ Global Bank Account, กำหนดเวลาหมดอายุของ Payment Request, วงเงินขั้นต่ำ-สูงสุดต่อรายการ, วงเงินรวมต่อวัน (Daily Tx Amount Limit) และจำนวนรายการต่อวัน (Daily Tx Count Limit)
- **แก้ไขข้อมูลร้านค้าที่มีอยู่** ด้วยฟอร์มเดียวกัน
- **จัดการ API Keys & Users ของร้านค้า**:
  - ดู Endpoint สำหรับเรียก API ทั้ง 4 แบบ (Pay-In, Pay-In (P2P), Pay-Out, Withdrawal) พร้อมปุ่ม Copy
  - ตั้งค่า Whitelist/Blacklist IP สำหรับจำกัดแหล่งที่มาของ request
  - สร้างและจัดการ API Key (ดูชื่อคีย์, สิทธิ์การใช้งาน, วันที่สร้าง, สถานะ)
  - เชิญผู้ใช้งานใหม่เข้าร้านค้า (Invite User) — ระบบสร้างลิงก์ลงทะเบียนให้ผู้ใช้ตั้งรหัสผ่านเอง แล้วแสดงในรายชื่อผู้ใช้พร้อมบทบาท (เช่น Owner) และสถานะ
