# บัญชีธนาคารสำหรับ Pay-In

วิดีโอนี้พาไปดูหน้าจัดการ **บัญชีธนาคาร (Bank Account)** ที่ใช้รับเงินฝั่ง Pay-In ในฝั่ง Admin สำหรับเพิ่ม แก้ไข หรือดูรายละเอียดบัญชีธนาคารที่ผูกไว้กับแต่ละร้านค้า

ดูจบแล้วคุณจะตั้งค่าบัญชีธนาคารสำหรับรับเงินให้ร้านค้าได้เอง — จำเป็นก่อนที่ร้านค้าใด ๆ จะเริ่มรับเงินผ่านระบบได้

## วิดีโอนี้พูดถึงอะไรบ้าง

- **ดูรายการบัญชีธนาคาร Pay-In ที่มีอยู่ทั้งหมด** พร้อมจำนวนร้านค้าที่ผูกใช้งาน (Merchant Count), วงเงิน, โควตา และสถานะ (Pending/Active)
- **เพิ่มบัญชีธนาคารใหม่** — เลือกธนาคาร (เช่น KTB), ประเภทการชำระเงิน PromptPay หรือ Native, เลขบัญชี, ชื่อ-เบอร์โทรที่ผูกกับ PromptPay, เลือกร้านค้าที่ใช้บัญชีนี้ (Merchant Specify), กฎการปัดเศษ (Round up/Truncate), วงเงินขั้นต่ำ-สูงสุดต่อรายการ และโควตารวมต่อวัน (Daily Quota)
- **แก้ไขบัญชีธนาคารที่มีอยู่** ด้วยฟอร์มเดียวกัน และหน้า "เชื่อมต่อร้านค้า" สำหรับเลือก/ยกเลิกร้านค้าที่ผูกกับบัญชีนี้
- **ดู Pay-In Tx Endpoint** ของบัญชี — URL สำหรับแจ้งเตือนผลธุรกรรม (Line Notification Endpoint) และจัดการ API Keys ของบัญชีนั้น
- **ดูภาพรวมบัญชีธนาคาร Bank Accounts** ของร้านค้าแต่ละราย แยกเป็น Pay-In Bank Accounts และ Pay-Out Bank Accounts พร้อมสถานะ Active/Selected
