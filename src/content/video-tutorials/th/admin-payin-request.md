# คำขอ Pay-In

วิดีโอนี้พาไปดูหน้า **Pay-In Request** ในฝั่ง Admin สำหรับดูและจัดการคำขอรับเงิน (Pay-In) ของทุกร้านค้าในองค์กรในที่เดียว

ดูจบแล้วคุณจะสร้างและอนุมัติคำขอรับเงินแทนร้านค้าได้เอง — เหมาะกับแอดมิน/ทีมซัพพอร์ตที่ต้องช่วยสร้างคำขอรับเงินหรือตรวจสอบรายการให้ร้านค้าด้วยตัวเอง

## วิดีโอนี้พูดถึงอะไรบ้าง

- **สร้างคำขอ Pay-In ใหม่** ผ่านหน้าต่าง QR Payment — เลือกร้านค้า, บัญชีธนาคาร (เลือกเองหรือให้ระบบเลือกอัตโนมัติ), จำนวนเงิน, ชื่อผู้ชำระเงิน, เลขอ้างอิง REF 1/REF 2 แล้วระบบสร้าง QR Code PromptPay ให้อัตโนมัติ
- **สร้างลิงก์/QR สำหรับให้ผู้ชำระเงินอัปโหลดสลิป** (Slip Upload Link) เพื่อแนบหลักฐานการโอนเงิน
- **ดูรายการคำขอ Pay-In ทั้งหมด** พร้อมคอลัมน์ REF, ร้านค้า, จำนวนเงิน, บัญชีธนาคารปลายทาง, ชื่อผู้ชำระเงิน และสถานะ (Pending/Identified/Approved/Rejected) พร้อมช่องค้นหาและตัวกรองตามช่วงวันที่/สถานะ
- **อนุมัติหรือปฏิเสธคำขอด้วยตนเอง** ผ่านหน้าต่าง Confirm Approve ที่สรุปร้านค้า บัญชี จำนวนเงิน REF และให้ใส่หมายเหตุก่อนกดอนุมัติ
- **ดูสรุปรายการและยอดคงเหลือ (Wallet)** ของแต่ละบัญชีธนาคาร — ตารางประวัติธุรกรรมที่แสดงรายการ Pay-In/Pay-Out พร้อมยอดบวก/ลบและยอดคงเหลือหลังรายการ
