# คำขอ Pay-Out

วิดีโอนี้พาไปดูหน้า **Pay-Out Request** ในฝั่ง Admin สำหรับดูและจัดการคำขอโอนเงิน (Pay-Out) ของทุกร้านค้าในองค์กรในที่เดียว

ดูจบแล้วคุณจะสร้างและอนุมัติคำขอถอน/โอนเงินแทนร้านค้าได้เอง — เหมาะกับแอดมิน/ทีมซัพพอร์ตที่ต้องช่วยดำเนินการถอนเงินหรือตรวจสอบคำขอโอนเงินให้ร้านค้า

## วิดีโอนี้พูดถึงอะไรบ้าง

- **เพิ่มบัญชีธนาคาร Pay-Out** สำหรับใช้โอนเงินออก — เลือกธนาคาร (เช่น BAY), ประเภท PromptPay, เลขบัญชี, เบอร์โทรที่ผูก PromptPay และกำหนดร้านค้าที่ใช้บัญชีนี้
- **สร้างคำขอ Pay-Out ใหม่** — เลือกร้านค้าต้นทาง, เลือกปลายทางเป็น Merchant (ร้านค้าอื่นในระบบ) หรือ Beneficiary (บัญชีภายนอก), จำนวนเงิน, เลขอ้างอิง REF 1/REF 2/REF 3
- **ดูรายการคำขอ Pay-Out ทั้งหมด** พร้อมคอลัมน์ร้านค้า, จำนวนเงิน, บัญชีต้นทาง-ปลายทาง และสถานะ (Pending/Approving/Approved)
- **อนุมัติคำขอ** และตัวอย่างข้อความแจ้งเตือนกรณียอดเงินในกระเป๋าของร้านค้าไม่พอ (Merchant wallet has insufficient balance) พร้อมบอกยอดคงเหลือปัจจุบันเทียบกับยอดที่ต้องการ
- **ดูยอดคงเหลือ (Wallet) ของบัญชีธนาคาร** ที่สะท้อนทั้งรายการ Pay-In (บวก) และ Pay-Out (ลบ) ในตารางประวัติเดียวกัน
