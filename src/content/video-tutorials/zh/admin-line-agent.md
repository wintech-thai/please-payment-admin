# LINE Agent

本视频介绍 Admin 端的 **LINE Agent** 设置页面——用于连接并设置通过 LINE 向相关人员发送的自动通知。

看完后，您将能够为团队设置 LINE 通知——适合希望通过 LINE 实时掌握重要事件、而不必一直盯着系统查看的团队。

## 视频内容

- **注册新的 LINE API Agent**——填写 Agent Code、说明（用于标识该 Agent 所属商户/用途）、LINE 用户名、LINE API Key、Agent Image Tag，并关联该 Agent 相关的银行账户
- **在"Agent 管理"表格中查看 Agent 列表**——通过开关启用/停用，并检查连接状态（如连接成功、ready）
- **查看某个 Agent 的 Event Messages**——Agent 通过 LINE 收发消息/事件的日志表，支持搜索及按 Channel/Event 筛选
