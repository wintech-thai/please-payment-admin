# Merchant

本视频介绍 Admin 端的 **Merchant** 页面——查看组织内所有商户的列表，包括新增商户、编辑现有商户信息，以及设置各商户的相关配置。

看完后，您将能够完整地管理商户——从新增商户到管理其 API 权限，适合需要新建商户或维护现有商户的管理员。

## 视频内容

- **查看组织内所有商户的列表**，支持搜索/筛选
- **新增商户**——填写 Organization ID、商户名称、联系邮箱和电话，设置费率（开户手续费/其他费用百分比）、启用或关闭共享的 Global Bank Account、设置 Payment Request 过期时间、单笔最小/最大限额、每日交易金额限额（Daily Tx Amount Limit）及每日交易笔数限额（Daily Tx Count Limit）
- **编辑现有商户信息**，使用同一套表单
- **管理商户的 API Keys & Users**：
  - 查看全部 4 种 API 端点（Pay-In、Pay-In (P2P)、Pay-Out、Withdrawal），可一键复制
  - 设置 Whitelist/Blacklist IP，限制请求来源
  - 创建并管理 API Key（名称、权限、创建日期、状态）
  - 邀请新用户加入商户——系统生成注册链接供用户自行设置密码，完成后会出现在用户列表中，并显示角色（如 Owner）与状态
