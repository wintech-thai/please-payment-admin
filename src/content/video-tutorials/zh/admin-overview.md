# Admin 概览

本视频介绍 Admin 端的 **Overview** 页面——管理员登录后看到的第一个页面，用于在一个地方查看**组织内所有商户**的交易汇总，无需逐一打开每个商户查看。

## 视频内容

- 如何选择要查看的时间范围（1 天、7 天、30 天或自定义），以及如何刷新数据
- 各汇总卡片的含义——收款金额、付款金额、提现金额、手续费，以及按状态（启用/停用）统计的商户数量
- 如何解读每日交易柱状图，以及按商户占比划分的饼图
- 如何在同一页面通过子标签切换查看不同类型的数据，例如收款、付款、手续费和提现
