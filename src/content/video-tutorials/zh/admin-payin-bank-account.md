# Pay-In 银行账户

本视频介绍 Admin 端用于接收 Pay-In 款项的**银行账户（Bank Account）**页面——新增、编辑或查看各商户关联的银行账户信息。

看完后，您将能够为商户设置收款银行账户——这是商户开始通过系统收款前必须完成的步骤。

## 视频内容

- **查看现有 Pay-In 银行账户列表**，包括关联商户数量、限额、额度及状态（Pending/Active）
- **新增银行账户**——选择银行（如 KTB）、付款方式 PromptPay 或 Native、账号、PromptPay 注册的姓名/电话、指定使用该账户的商户（Merchant Specify）、取整规则（Round up/Truncate）、单笔最小/最大限额及每日额度
- **编辑现有银行账户**（使用同一表单），以及在"关联商户"页面选择/移除使用该账户的商户
- **查看银行账户的 Pay-In Tx Endpoint**——通知端点网址（Line Notification Endpoint）及管理该账户的 API Keys
- **查看商户的银行账户总览**，分为 Pay-In 银行账户与 Pay-Out 银行账户，并显示其 Active/Selected 状态
