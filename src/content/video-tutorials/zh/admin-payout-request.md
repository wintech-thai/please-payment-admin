# Pay-Out 请求

本视频介绍 Admin 端的 **Pay-Out Request** 页面——在一个地方查看和管理组织内所有商户的 Pay-Out 请求。

看完后，您将能够代商户创建并批准提现/转账请求——适合需要为商户处理提现或审核转账请求的管理员/客服人员。

## 视频内容

- **新增用于转出资金的 Pay-Out 银行账户**——选择银行（如 BAY）、PromptPay 类型、账号、注册的电话号码，并指定使用该账户的商户
- **创建新的 Pay-Out 请求**——选择来源商户、目的地（系统内其他商户 Merchant 或外部 Beneficiary）、金额、参考编号 REF 1/REF 2/REF 3
- **查看 Pay-Out 请求列表**，包含商户、金额、来源/目的账户及状态（待处理/审批中/已批准）等栏位
- **批准请求**，以及"Merchant wallet has insufficient balance"（商户钱包余额不足）提示示例，显示当前余额与所需金额的对比
- **查看银行账户的钱包余额**，在同一笔交易记录表中反映 Pay-In（入账）与 Pay-Out（出账）的往来
